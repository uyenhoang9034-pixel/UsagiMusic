# UsagiMusic

Một repo chạy 3 bot nhạc Discord dùng chung code:

- Usagi Music 1
- Usagi Music 2
- Usagi Music 3

## Biến môi trường bắt buộc

```env
MUSIC_BOT_1_TOKEN=
MUSIC_BOT_2_TOKEN=
MUSIC_BOT_3_TOKEN=
```

Không commit token lên GitHub.

Có thể dùng Lavalink mặc định từ `lavalink/nodes.json` hoặc override bằng các biến `LAVALINK_*` giống Tiên Tôn.
